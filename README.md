# دفتر المذاكرة

تطبيق ويب عربي (RTL) من صفحة واحدة لتنظيم المذاكرة: إدارة المواد والشابترات، تواريخ الاختبارات، جدول دراسي ذكي قابل للسحب والإفلات، خطط مذاكرة، وأسئلة متوقعة. يعمل بالكامل في المتصفح: لا خادم، ولا تسجيل دخول، ولا إرسال بيانات.

مُعدّ مسبقاً بخطة **هندسة الاتصالات — جامعة طيبة** (10 مستويات)، ومواد المستوى الأول مضافة بشابترات مقترحة.

## التشغيل

- **أسهل طريقة:** افتح `index.html` في المتصفح مباشرة (Chrome / Edge / Firefox).
- **ملف واحد للجوال:** `npm run build` ينتج `dist/study-notebook.html`، وهو ملف مستقل يمكن إرساله للجوال وفتحه.
- **الاختبارات:** `npm test` (يتطلب Node 18+).

```
index.html          هيكل الواجهة وقسم «كيفية الاستخدام»
styles.css          التنسيق (فاتح/داكن، متجاوب)
js/data.js          الخطة الدراسية، الشابترات المقترحة، التقنيات، النصائح، قوالب الأسئلة
js/scheduler.js     خوارزمية توليد الجدول (دوال نقية، تعمل في المتصفح وNode)
js/app.js           الحالة، الحفظ في localStorage، العرض، والأحداث
tests/              اختبارات الخوارزمية وحالات الحافة (node:test)
tools/build.js      بناء نسخة من ملف واحد
```

المكتبة الخارجية الوحيدة هي SortableJS (عبر cdnjs) لدعم السحب باللمس. إن لم تُحمَّل يعمل السحب الأصلي للمتصفح، ويمكن نقل أي جلسة من نافذتها أيضاً.

## 1. تحليل المتطلبات وبنية البيانات

| المتطلب | التنفيذ |
|---|---|
| مواد غير محدودة، تعديل/حذف | تبويب «المواد»: نموذج إضافة، تعديل مباشر للشابترات داخل البطاقة |
| تواريخ الاختبارات والعد التنازلي | حقل تاريخ لكل مادة، ترتيب تلقائي، ألوان حسب القرب، مع التاريخ الهجري (أم القرى) |
| جدول ذكي | `Scheduler.generateSchedule` (القسم 4) |
| جدول أسبوعي + سحب وإفلات | شبكة الأيام × الفترات، SortableJS أو السحب الأصلي |
| خطط وتقنيات مذاكرة | تبويب «خطط المذاكرة» من `data.js` حسب الصعوبة ونوع المادة |
| أسئلة متوقعة | لكل شابتر: إضافة يدوية، توليد إرشادي، تصنيف، وتتبع الحالة |
| إحصائيات وتقدم | الرئيسية: الشابترات، الساعات، الأسئلة، الجلسات، والمتأخرات |
| حفظ واستيراد/تصدير | `localStorage` تلقائياً + JSON (تنزيل أو نسخ/لصق) |

**بنية البيانات** (هكذا تُحفظ في `localStorage` وفي ملف التصدير):

```json
{
  "version": 1,
  "settings": {
    "dailyHours": 4, "sessionMinutes": 50, "breakMinutes": 10, "reviewDays": 2,
    "restDays": [5], "spacedReview": true, "activeTime": "evening", "startTime": ""
  },
  "subjects": [{
    "id": "sub_x1", "name": "فيزياء (1)", "code": "PHYS 103", "teacher": "",
    "difficulty": "hard", "type": "apply", "source": "book",
    "examDate": "2026-10-20", "colorIndex": 0,
    "chapters": [{
      "id": "ch_a1", "title": "الحركة في بعد واحد", "pages": 22, "done": false, "inExam": true,
      "topics": ["السرعة المتوسطة واللحظية", "التسارع"],
      "questions": [{ "id": "q_1", "text": "احسب ...", "type": "problem", "status": "review", "generated": true }]
    }]
  }],
  "sessions": [{
    "id": "s_1", "date": "2026-10-01", "slot": 0, "subjectId": "sub_x1",
    "kind": "study", "chapterIds": ["ch_a1"], "part": 1, "parts": 3,
    "minutes": 50, "done": false, "manual": false
  }],
  "warnings": [{ "level": "warn", "message": "..." }],
  "focusMinutes": 0
}
```

- `difficulty`: `easy | medium | hard` · `type`: `memorize | understand | apply | math | language` · `source`: `book | notes | lectures`
- `kind`: `study` (مذاكرة) · `review` (مراجعة نهائية) · `spaced` (مراجعة متباعدة) · `quick` (مراجعة يوم الاختبار)
- `question.type`: `mcq | essay | tf | problem` · `question.status`: `todo | done | review`
- `done`: أنهيت مذاكرة الشابتر فلا يُجدول مجدداً · `inExam`: الشابتر مقرر في الاختبار؛ الجدول والمراجعة والتقدم تشمل المقرر فقط.
- التقدم **مشتق** من الجلسات المنجزة ولا يُخزَّن مكرراً.

## 4. منطق خوارزمية توليد الجدول

الدالة `generateSchedule({ subjects, settings, today, history })` نقية (لا تلمس الواجهة) وتُرجع `{ sessions, warnings, meta }`.

1. **تنظيف الإعدادات:** ساعات فارغة أو صفر ← 4 ساعات مع تنبيه. عدد الفترات اليومية = ⌊(دقائق اليوم + الراحة) ÷ (الجلسة + الراحة)⌋، وأقلها فترة واحدة. أيام المراجعة لا تقل عن 2.
2. **تجهيز كل مادة:** تُستبعد المادة بلا تاريخ أو بتاريخ ماضٍ مع تنبيه. احتياج كل شابتر من الجلسات يُحسب من الصفحات إن وُجدت (سهل 20، متوسط 12، صعب 8 صفحات لكل جلسة، وبحد أقصى 6 جلسات)، وإلا من الصعوبة (1 / 2 / 3). تُخصم الأجزاء المنجزة في جداول سابقة، ولا يُعاد جدولة شابتر عُلّم منجزاً.
3. **كشف التعارض:** اختباران في يوم واحد ← تنبيه «تعارض». اختباران متتاليان ← ملاحظة.
4. **السعة اليومية:** لكل يوم من اليوم حتى آخر اختبار: عدد الفترات، أو صفر في أيام الراحة، مطروحاً منه الفترات التي تشغلها جلسات منجزة. إذا كانت كل الأيام قبل اختبار ما أيام راحة، تُفتح للمذاكرة مع تنبيه.
5. **النوافذ:** آخر N يوم عمل قبل الاختبار (N = أيام المراجعة) نافذة مراجعة، وما قبلها نافذة مذاكرة. إذا ضاق الوقت تُقلَّص المراجعة ليبقى يوم مذاكرة واحد على الأقل. ومع يوم واحد فقط يُعد «يوماً مكثفاً» فيه مذاكرة ومراجعة معاً.
6. **المرحلة 1: المراجعة النهائية أولاً.** تُحجز جلسات المراجعة قبل كل اختبار: نصف اليوم كحد أقصى في اليوم الأخير، وثلثه في أيام المراجعة الأخرى، وإن كانت مواد أخرى تحتاج اليوم فللمراجعة 60% منه كحد أقصى.
7. **المرحلة 2: توزيع الشابترات.**
   - *المرور المتوازن:* لكل يوم تحصل كل مادة على حصة ⌈المتبقي ÷ الأيام المتبقية⌉، والأولوية لأعلى (المتبقي ÷ الأيام − ما أخذته اليوم)، مع خصم نقطة إذا تتابعت المادة نفسها ثلاث فترات، لتتنوع المواد خلال اليوم.
   - إن لم تتسع كل الجلسات: *مرور احتياطي* بقاعدة «الأقرب اختباراً أولاً» (EDF)، مع السماح بإكمال الشابترات في أيام المراجعة.
   - إن بقيت جلسات بلا مكان: **ضغط عادل**، إذ تتنازل كل المواد المتداخلة زمنياً عن جلسات واحدة تلو الأخرى، بدءاً بالأعلى في «جلسات لكل شابتر»، ولا تنزل أي مادة عن جلسة لكل شابتر. بعدها فقط تُدمج عدة شابترات في جلسة واحدة. تتكرر المحاولة حتى يتسع الجدول، مع تنبيه يذكر عدد الجلسات قبل الضغط وبعده.
8. **المرحلة 3: المراجعة المتباعدة.** يُملأ الوقت الفارغ بجلسة واحدة يومياً لكل مادة، تراجع الشابتر الذي مرّ على آخر مذاكرة له يومان أو أكثر (الأقدم أولاً). وفي أيام المراجعة تضاف جلسة حل أسئلة إن بقي وقت.
9. **يوم الاختبار نفسه:** جلسة «مراجعة سريعة» فقط، مع تنبيه عاجل.
10. **محتوى المراجعات:** تُقسم شابترات المادة على جلسات المراجعة بالتتابع، وآخر جلسة قبل الاختبار «مراجعة شاملة وحل نموذج اختبار».
11. **الترتيب داخل اليوم:** المراجعة السريعة، ثم المراجعة النهائية للأقرب اختباراً، ثم المذاكرة من الأصعب إلى الأسهل (في أول اليوم، وقت ذروة التركيز)، ثم المراجعة المتباعدة. تُسند الفترات متجاوزةً الفترات المشغولة بجلسات منجزة.

عند إعادة التوليد تُحفظ الجلسات المنجزة كما هي، ويُعاد توزيع غير المنجز كله (بما فيه المتأخر والمعدّل يدوياً، بعد تأكيد).

## 5. حالات الحافة وكيفية التعامل معها

| الحالة | المعالجة |
|---|---|
| شابترات خارج الاختبار (`inExam: false`) | لا تُجدول ولا تُراجع ولا تدخل نسبة الإنجاز؛ وإن لم يُحدد أي شابتر مقرر فمراجعة عامة + تنبيه |
| مادة بدون شابترات | تُجدول لها مراجعة عامة فقط في أيام المراجعة + تنبيه لإضافة الشابترات |
| تاريخ اختبار ماضٍ | تُستبعد المادة من الجدول + تنبيه، وتظهر «انتهى» في بطاقتها |
| صفر أيام متبقية (الاختبار اليوم) | جلسة «مراجعة سريعة» واحدة اليوم + تنبيه عاجل |
| يوم واحد متبقٍ | يوم مكثف: جلسة مراجعة + بقية الفترات مذاكرة مدمجة تغطي كل الشابترات |
| عدم إدخال ساعات المذاكرة (أو صفر) | تُستخدم 4 ساعات افتراضياً + تنبيه |
| تعارض مواعيد اختبارات (نفس اليوم) | تنبيه «تعارض مواعيد» + تقسيم وقت المراجعة بين المادتين |
| اختباران متتاليان | ملاحظة بإنهاء مذاكرة الثانية مبكراً؛ الخوارزمية تقدّمها تلقائياً |
| مادة بلا تاريخ اختبار | لا تدخل الجدول + ملاحظة |
| الوقت لا يكفي كل الشابترات | تقليص عادل للأجزاء ثم دمج الشابترات + تنبيه بالأرقام |
| كل الأيام المتبقية أيام راحة | تُفتح للمذاكرة + تنبيه؛ واختيار أيام الأسبوع السبعة للراحة يُتجاهل |
| كل شابترات المادة منجزة | مراجعة فقط + ملاحظة |
| جلسات فائتة غير منجزة | تظهر بإطار أحمر «متأخرة» في الجدول والرئيسية + زر إعادة التوليد |
| نقل جلسة يدوياً إلى يوم الاختبار أو بعده | يُسمح بالنقل مع تنبيه |
| تعذّر الحفظ (وضع التصفح الخاص) | التطبيق يعمل + تنبيه بتصدير البيانات |
| ملف استيراد تالف أو غير صالح | رسالة خطأ واضحة، والبيانات الحالية لا تتغير |
| حذف شابتر مرتبط بجلسات | تُزال الإشارة إليه، وتُحذف جلسات المذاكرة التي فرغت (غير المنجزة فقط) |

كل هذه الحالات مغطاة في `tests/scheduler.test.js` (16 اختباراً).

## 6. كيفية الاستخدام (نسخة جاهزة داخل التطبيق)

1. **أضف موادك:** من «المواد» اضغط «إضافة مادة»، واكتب الاسم والصعوبة والنوع. اكتب الشابترات سطراً لكل شابتر، والصفحات بعد `|` مثل `المتجهات | 24`، أو اكتب العدد فقط. مواد المستوى الأول مضافة مسبقاً بشابترات مقترحة فعدّلها لتطابق منهجك، ولمواد مستوى آخر افتح «خطتي الجامعية».
2. **أدخل تواريخ الاختبارات** من بطاقة كل مادة. يُحسب المتبقي وتُرتب المواد وتُلوَّن: أحمر أقل من 7 أيام، برتقالي 7–14، أخضر أكثر من 14.
3. **اضبط وقتك وولّد الجدول:** من «الجدول» أدخل الساعات ومدة الجلسة ووقت النشاط وأيام الراحة، ثم «توليد الجدول». يُحجز يومان على الأقل للمراجعة قبل كل اختبار، وتوضع المواد الأصعب في أول اليوم.
4. **عدّل وتابع:** اسحب أي جلسة وأفلتها في مكان آخر، أو اضغطها لنقلها أو حذفها. علّم «تمت» لتتحدث الإحصائيات. الفائت يظهر بالأحمر، و«إعادة التوليد» توزعه من جديد دون المساس بالمنجز.
5. **الخطط والأسئلة:** «خطط المذاكرة» تعرض التقنيات المناسبة وتوزيع الراحة لكل مادة. وفي «الأسئلة المتوقعة» أضف أسئلتك أو ولّد أسئلة إرشادية، وحدّث حالة كل سؤال.

**بياناتك** محفوظة في متصفحك فقط. صدّر نسخة JSON من «كيفية الاستخدام ← بياناتك» بين حين وآخر.

## 7. اقتراحات تطوير مستقبلية

1. تحويله إلى PWA (Service Worker + أيقونة) ليُثبَّت على الجوال ويعمل دون اتصال تماماً.
2. تنبيهات مجدولة بموعد الجلسة عبر Notifications API.
3. التكرار المتباعد مبني على أداء الأسئلة: السؤال المعلّم «يحتاج مراجعة» يقرّب موعد مراجعة شابتره.
4. تصدير الجدول بصيغة iCalendar (`.ics`) لإضافته لتقويم الجوال.
5. حساب المعدل المتوقع من درجات الاختبارات ووحدات كل مقرر في الخطة الجامعية.
